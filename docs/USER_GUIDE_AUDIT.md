## D. Structure and delivery gaps

1. One guide for all roles. A teacher sees finance, HR and hostel chapters. Proposal: tag chapters/sections by role and filter, with a "For my role" default.
2. No Urdu, no screenshots, no video.
3. No ownership: the JSON is regenerated from `generate_user_guide.py`, so fixes must go there. Proposal: add a one-line checklist to PR practice ("changed a page label? update the guide").
4. Header "Updated" date comes from `generatedAt`; it is shown to users as if the whole guide was reviewed on that date.
